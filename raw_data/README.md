# Raw data

This directory is intentionally empty in Git. The public datasets are downloaded by the pipeline.

- `python scripts/p1_download_data.py` downloads the three GSE114412 Stage-5 files.
- `python scripts/p12_download_preflight_GSE175634.py` downloads and validates the six GSE175634 files.

The original analysis used approximately **1.14 GB of compressed raw data**. See [`../docs/raw_data_manifest.csv`](../docs/raw_data_manifest.csv) for the expected filenames and sizes from the reference run.

Do not commit the downloaded matrices to GitHub; they are public GEO source data and are regenerated by the download scripts.
