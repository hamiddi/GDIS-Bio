------------------------------------------------------------------------------------------------
GDIS circular-shift localization p-value: 4.99975e-05

The exact paired comparisons use only the four independent branch x differentiation analyses and therefore have very limited resolution. A non-significant paired test must NOT be interpreted as evidence of equivalence.

The circular-shift tests assess biological alignment relative to this trajectory while preserving each profile's internal structure. They do not replace independent-dataset validation.

The median NEUROG3-early landmark is not the true transition-onset time. A statistically early signed peak therefore supports earlier positioning relative to the state median, not proven prospective prediction.

No GDIS parameter or analysis choice was changed based on these null-test results.
