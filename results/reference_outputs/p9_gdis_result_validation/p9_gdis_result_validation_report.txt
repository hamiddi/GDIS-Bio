8. RESULT SUMMARY
--------------------------------------------------------------------------------------------
Observed primary pattern:
  - The global GDIS maximum localizes to the NEUROG3-early transition phase in all four branch x differentiation analyses.
  - The data-driven transition-energy center occurs before the median NEUROG3-early landmark in all four groups.
  - Mean separation from transition-energy center to median NEUROG3-early landmark: 0.033958 pseudotime units.
  - Observed range of that separation: 0.016311 to 0.050663.
  - This is evidence of reproducible transition localization relative to a pre-frozen state landmark; it is not by itself proof of prediction before true biological onset.
  - A distinct later global GDIS maximum at the terminal SC-EC/SC-beta state is not supported by the primary result.

Recommended next step:
Benchmark the frozen GDIS result against conventional early-warning / transition metrics using the same windows and biological landmarks.
